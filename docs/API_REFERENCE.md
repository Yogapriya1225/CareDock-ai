# API Reference — CareDock AI

Full interactive docs are auto-generated by FastAPI at `http://localhost:8000/docs`
(Swagger UI) or `/redoc` once the backend is running. This file is a quick summary.

## Authentication (`/api/auth`)
| Method | Path        | Auth | Description |
|--------|-------------|------|-------------|
| POST   | `/register` | none | Create a user (patient/doctor/caregiver/admin) |
| POST   | `/login`    | none | Returns JWT access token + user object |
| GET    | `/me`       | any  | Returns the current authenticated user |

## Patient (`/api/patient`)
| Method | Path                          | Auth              | Description |
|--------|-------------------------------|-------------------|-------------|
| POST   | `/`                           | doctor, admin     | Create a patient profile |
| GET    | `/{id}`                       | any               | Get patient profile |
| POST   | `/schedule`                   | doctor, admin     | Create a medicine schedule entry |
| GET    | `/{id}/schedule`              | any               | Active medicine schedules |
| GET    | `/{id}/history`               | any               | Dose history (taken/missed) |
| GET    | `/{id}/activity`              | any               | PIR activity logs |
| GET    | `/{id}/recovery-scores`       | any               | Historical recovery scores |
| GET    | `/{id}/alerts`                | any               | All alerts for the patient |
| GET    | `/{id}/dashboard`             | any               | Aggregated dashboard payload |

## Doctor (`/api/doctor`)
| Method | Path                    | Auth           | Description |
|--------|-------------------------|----------------|-------------|
| GET    | `/patients`             | doctor, admin  | List/search assigned patients with latest risk |
| GET    | `/high-risk-patients`   | doctor, admin  | Patients currently flagged high risk |
| GET    | `/alerts/live`          | doctor, admin  | Unresolved alerts across all patients |

## Caregiver (`/api/caregiver`)
| Method | Path                        | Auth              | Description |
|--------|-----------------------------|-------------------|-------------|
| GET    | `/{caregiver_id}/patients`  | caregiver, admin  | Status snapshot of linked patients |

## Admin (`/api/admin`)
| Method | Path                    | Auth  | Description |
|--------|-------------------------|-------|-------------|
| GET    | `/users`                | admin | List all users |
| GET    | `/hospitals`            | admin | List hospitals |
| POST   | `/hospitals`            | admin | Create a hospital |
| GET    | `/analytics/overview`   | admin | System-wide counts (patients, doctors, alerts, high-risk) |

## ESP32 Device (`/api/esp32`)
| Method | Path       | Auth                    | Description |
|--------|------------|-------------------------|-------------|
| POST   | `/ingest`  | device_secret in body   | Ingest a sensor reading; returns hardware control instructions |

Request body (`ESP32Payload`):
```json
{
  "device_id": "caredock-box-001",
  "device_secret": "change_this_device_secret",
  "weight_grams": 182.4,
  "medicine_taken_button": false,
  "pir_motion": true,
  "sos_pressed": false,
  "timestamp": "2026-09-06T10:00:00"
}
```
Response (`ESP32Response`):
```json
{
  "buzzer": false,
  "led_color": "green",
  "oled_message": "All good",
  "alert_triggered": false
}
```

## Machine Learning (`/api/ml`)
| Method | Path                              | Auth | Description |
|--------|------------------------------------|------|-------------|
| POST   | `/{patient_id}/recompute-risk`    | any  | Recomputes recovery risk/anomaly/recommendation from the last 7 days of data |

## Chatbot (`/api/chatbot`)
| Method | Path                       | Auth | Description |
|--------|----------------------------|------|-------------|
| POST   | `/ask`                     | any  | Send a message to the Gemma 3 assistant, persists history |
| GET    | `/{patient_id}/history`    | any  | Retrieve stored chat history |

---

All protected endpoints expect `Authorization: Bearer <jwt>`. Tokens are obtained
from `/api/auth/login` and expire per `ACCESS_TOKEN_EXPIRE_MINUTES` in `.env`.
